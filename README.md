# AiLex - AI-powered Browser Extension

Браузерное расширение с чат-интерфейсом для взаимодействия с различными AI моделями (OpenAI, Anthropic и другие).

## Возможности

- 🤖 Поддержка множества AI провайдеров: OpenAI, Anthropic, OpenRouter, Grok, Gemini, LM Studio
- 💬 Чат с AI с поддержкой streaming ответов
- 🔍 **Продвинутые фильтры моделей**:
  - Фильтрация по минимальной длине контекста (slider от min до max)
  - Фильтрация по входящим модальностям (text, image, file)
  - Фильтрация по исходящим модальностям (text, image)
  - Фильтрация по AI операторам
  - Интерактивный выбор модели из отфильтрованного списка
  - Сохранение фильтров в localStorage
  - Визуальный индикатор активных фильтров
- 📄 Автоматическое извлечение контекста текущей страницы
- 📎 **Прикрепление файлов и мультимодальность**:
  - 📄 Прикрепление файлов (документы, код, данные)
  - 🖼️ Прикрепление изображений с превью
  - 📸 Захват скриншотов с выбором области
  - 📷 Съемка фото с веб-камеры
  - 🎤 Голосовой ввод с распознаванием речи
  - 🎯 Выбор DOM элементов со страницы
  - 🔗 **Ссылки на вкладки браузера** через "@" для сравнения и анализа страниц
  - ✅ Автоматическая проверка поддержки модели
  - 🗜️ Сжатие изображений при превышении лимита
- 🔧 **Система инструментов с function calling**: встроенные и пользовательские инструменты, интеграция с AI
  - 📄 Саммаризация страниц
  - 📧 Сбор контактов (email, телефоны, Telegram)
  - ✏️ Автозаполнение форм
  - 🔍 **Парсинг множества страниц**: автоматический поиск CSS селекторов, сбор данных с множества страниц, умная фильтрация ссылок
- 🖱️ **Контекстное меню для выделенного текста**: 24 команды в 6 категориях + пользовательские инструкции
- 📱 Sidepanel интерфейс
- 🌙 Темная/светлая тема
- 🌍 Мультиязычность (EN/RU)
- 💾 История диалогов с различными режимами сохранения
- 📂 Организация чатов в папки
- 🔍 Поиск по истории чатов
- 🏷️ Автоматическое именование чатов из первого сообщения
- 📊 Отображение использованных операторов и токенов для каждого чата
- 🔗 Быстрый переход к сайту из истории чата
- 📊 **Вкладка History с двумя режимами**:
  - 💬 **Чаты**: история всех диалогов с группировкой по дням, пагинацией (30 чатов/страница)
  - 📈 **Статистика**: детальная аналитика использования токенов с фильтрами и графиками
- 💾 **Экспорт/Импорт настроек**: резервное копирование и перенос всех настроек расширения
- 🔧 **Режим разработчика**: панель отладки API запросов без DevTools

## Технологии

- **Frontend**: React + TypeScript
- **Build**: Vite + @crxjs/vite-plugin
- **UI**: shadcn/ui + TailwindCSS
- **State**: Zustand
- **Database**: IndexedDB (idb)
- **Icons**: lucide-react

## Установка

```bash
# Установка зависимостей
npm install

# Разработка
npm run dev

# Сборка для production
npm run build:prod
```

3. Нажмите "Загрузить распакованное расширение"

## Настройка

### AI Провайдеры

1. Откройте расширение
2. Перейдите в "Настройки" → "Операторы"
3. Введите API ключ для нужного провайдера
4. Нажмите "Тест" для проверки подключения
5. Выберите модель из списка

### Фильтрация моделей

Расширение предоставляет мощную систему фильтрации для быстрого поиска нужной AI модели среди сотен доступных моделей.

#### Как использовать

1. Откройте dropdown выбора модели (кнопка с логотипом оператора)
2. В поле поиска справа нажмите кнопку с иконкой фильтра (Settings2)
3. В открывшемся диалоге настройте нужные фильтры
4. Список моделей обновится автоматически
5. Выберите модель из отфильтрованного списка или закройте диалог

#### Доступные фильтры

**1. Минимальная длина контекста**
- Slider для выбора минимального размера контекстного окна
- Диапазон от минимального до максимального значения в базе данных
- Форматирование: K (тысячи), M (миллионы) токенов
- Полезно для задач с большими документами

**2. Входящие модальности (Input)**
- Toggle кнопки для выбора типов входных данных:
  - 📝 Text - текстовый ввод
  - 🖼️ Image - поддержка изображений
  - 📄 File - поддержка файлов/документов
- Модель должна поддерживать ВСЕ выбранные модальности

**3. Исходящие модальности (Output)**
- Toggle кнопки для типов выходных данных:
  - 📝 Text - текстовый вывод
  - 🖼️ Image - генерация изображений
- Модель должна поддерживать ВСЕ выбранные модальности

**4. AI Операторы**
- Фильтрация по провайдерам (OpenAI, Anthropic, Google, Grok и др.)
- Toggle кнопки с логотипами операторов
- Можно выбрать несколько операторов одновременно

#### Особенности

- **Автоматическое сохранение**: Фильтры сохраняются в localStorage и восстанавливаются при следующем открытии
- **Визуальный индикатор**: Красная точка на кнопке фильтра показывает, что фильтры активны
- **Счетчик моделей**: Отображается количество найденных моделей
- **Кнопка сброса**: Быстрый возврат к настройкам по умолчанию
- **Интеграция с поиском**: Фильтры работают совместно с текстовым поиском
- **Компактный UI**: Все элементы управления размещены компактно для удобства
- **Скроллбар**: Длинный список моделей прокручивается (макс. высота 400px)

**Компоненты:**
- `src/ui/components/chat/ModelFiltersDialog.tsx` - диалог с фильтрами
- `src/ui/components/chat/ModelSelect.tsx` - интеграция фильтров в dropdown
- `src/ui/components/ui/slider.tsx` - компонент slider

**Хуки:**

**Переводы:**

### Личная информация

### Экспорт и импорт настроек

Система экспорта/импорта позволяет создавать резервные копии всех настроек расширения и переносить их между браузерами или устройствами.

#### Экспорт настроек

1. Откройте "Настройки" → "Общие"
2. Прокрутите до раздела "Управление настройками"
3. Нажмите кнопку "Экспорт настроек"
4. Файл `ailex-settings-YYYY-MM-DDTHH-MM-SS.json` автоматически загрузится

**Что экспортируется:**
- **Операторы**: API ключи (расшифрованные), выбранные модели, custom endpoints
- **Общие настройки**: тема, язык, режим истории, показ AI подсказок, режим разработчика
- **Личная информация**: все заполненные поля профиля
- **Инструкции**: общая инструкция и инструкции для конкретных сайтов
- **Метаданные шифрования**: для корректной работы с API ключами

#### Импорт настроек

1. Откройте "Настройки" → "Общие"
2. Нажмите кнопку "Импорт настроек"
3. Выберите JSON файл с экспортированными настройками
4. Система автоматически проверит валидность файла
5. Выберите чекбоксами, какие секции импортировать:
   - ☑ Операторы (API ключи, модели, endpoints)
   - ☑ Общие настройки (тема, язык, режим истории)
   - ☑ Личная информация
   - ☑ Инструкции (общая и для сайтов)
6. Нажмите "Импортировать"

**Особенности:**
- ✅ **Валидация данных**: проверка структуры и версии формата
- ✅ **Выборочный импорт**: можно импортировать только нужные секции
- ✅ **Безопасность API ключей**: ключи экспортируются в открытом виде вместе с метаданными шифрования
- ✅ **Обработка ошибок**: подробные сообщения об ошибках при невалидном файле
- ✅ **Замена настроек**: все существующие настройки обновляются на новые
- ✅ **Информация о файле**: отображение версии и даты экспорта перед импортом

**Сценарии использования:**
- 📦 Резервное копирование настроек перед обновлением расширения
- 🔄 Перенос настроек между компьютерами
- 👥 Обмен конфигурациями с коллегами
- 🔧 Быстрое восстановление после переустановки браузера

**Файлы функционала:**
- `src/shared/utils/encryption.ts` - экспорт метаданных шифрования
- `src/shared/stores/settingsStore.ts` - логика экспорта/импорта/валидации
- `src/ui/components/settings/ImportDialog.tsx` - UI диалога импорта
- `src/ui/components/settings/GeneralTab.tsx` - кнопки экспорта/импорта

## Использование

### Основной чат

1. Кликните на иконку расширения для открытия sidepanel
2. Выберите AI модель из списка
3. Введите запрос и отправьте
4. Включите "Текущая страница" для передачи контекста страницы

### История чатов

1. Нажмите на иконку "История" в хедере чата
2. В открывшейся панели вы увидите список всех чатов
3. Используйте поиск для быстрого нахождения нужного чата
4. Наведите курсор на чат для доступа к меню действий:
   - **Переименовать**: изменить название чата
   - **Переместить**: переместить чат в папку
   - **Удалить**: удалить чат безвозвратно

### Вкладка History

Полноценная страница с историей и аналитикой использования AI:

#### Режим "Чаты"

История всех диалогов с удобной навигацией:

- **Группировка по дням**: Сегодня, Вчера, N дней назад
- **Информация о чате**:
  - Название (генерируется автоматически)
  - Сайт с быстрым переходом (клик на badge)
  - Иконки использованных операторов
  - Количество токенов
  - Дата и время последнего обновления
- **Пагинация**: 30 чатов на страницу с навигацией
- **Клик на чат**: автоматически открывает сайт и загружает историю

#### Режим "Статистика"

Детальная аналитика использования токенов:

**Фильтры:**
- **Быстрый выбор периода**: Текущая неделя, Текущий месяц, Предыдущая неделя, Предыдущий месяц
- **Календарь дат**: От/До с валидацией (нельзя выбрать некорректный диапазон)
- **Фильтр по оператору**: Все операторы или конкретный AI провайдер

**Общие метрики:**
- Общее количество сообщений за период
- Общее количество токенов за период

**Графики:**

1. **Tokens per Day** (Bar Chart):
   - Динамика использования токенов по дням
   - Диапазон дат в подзаголовке
   - Tooltip с точным количеством

2. **By Operators** (Horizontal Bar Chart):
   - Распределение токенов по AI операторам
   - Сортировка по убыванию использования
   - Показывает все использованные операторы

3. **By Models** (Horizontal Bar Chart):
   - Топ-10 моделей по использованию токенов
   - Сортировка по убыванию
   - Автоматическое сокращение длинных названий

**Особенности:**
- Все графики адаптивные
- Tooltips с подсказками для полей фильтров
- Данные сохраняются в IndexedDB автоматически при каждом запросе
- Обработка пустых состояний ("No data available")

### Работа с папками

1. Нажмите кнопку "Новая папка" в панели истории
2. Введите название папки (по умолчанию "Безымянная папка")
3. Перемещайте чаты в папки через меню чата → "Переместить"
4. Нажмите на папку для раскрытия/скрытия чатов внутри
5. Наведите курсор на папку для доступа к меню:
   - **Переименовать**: изменить название папки
   - **Удалить**: удалить папку (чаты останутся)

### Информация о чатах

Для каждого чата отображается:
- **Название**: автоматически генерируется из первого сообщения
- **Сайт** (синий badge): кликабелен, открывает сайт в текущей вкладке
- **Операторы**: иконки использованных AI операторов в чате
- **Токены** (серый badge): общее количество использованных токенов
- **Дата создания**: заменяется на меню при наведении курсора

### Прикрепление файлов и мультимодальность

Расширение поддерживает работу с различными типами контента для мультимодальных AI моделей:

#### 1. Прикрепление файлов

- Поддерживаемые форматы:
  - **Документы**: PDF, DOC, DOCX, TXT, MD
  - **Код**: JS, TS, PY, JAVA, GO, RS, C, CPP и др.
  - **Данные**: JSON, CSV, XML, YAML
- Текстовые файлы читаются как текст
- Бинарные файлы конвертируются в Base64
- Отображение в виде badge с иконкой файла
- Лимит размера: 10 MB (настраивается)

#### 2. Прикрепление изображений

- Выбор фото из галереи
- Превью в виде квадрата над полем ввода
- Автоматическое сжатие при превышении лимита
- Сохранение в историю в Base64
- Полноэкранный просмотр по клику
- Лимит размера: 5 MB (настраивается)

#### 3. Захват скриншотов

- Интерактивный выбор области экрана
- Затемнение экрана с подсветкой выбранной области
- Автоматическое сжатие
- Отмена выбора: Esc или клик на поле ввода
- Результат сохраняется как изображение

#### 4. Съемка с веб-камеры

- Активация камеры устройства
- Превью перед съемкой
- Обработка разрешений
- Сжатие и сохранение фото

#### 5. Выбор DOM элементов

- Интерактивный выбор элементов на странице
- Подсветка при наведении
- Извлечение innerHTML элемента
- Отображение в виде красного badge
- Отправка содержимого как контекст для AI
- Сохранение XPath для повторного доступа
- Отмена выбора: Esc или клик на поле ввода

#### 6. Голосовой ввод

- Распознавание речи с помощью Web Speech API
- Открытие в отдельном popup-окне с красивым UI
- Автоматический запуск записи при открытии
- Поддержка темной и светлой темы
- Определение языка из настроек браузера
- Непрерывное распознавание речи
- Визуальная индикация процесса записи (пульсирующая иконка)
- Просмотр распознанного текста в реальном времени
- Кнопки управления: Start/Stop, Done, Cancel
- Автоматическое добавление текста в поле ввода
- Обработка ошибок (нет разрешения, нет речи, сетевые проблемы)
- Горячая клавиша Esc для закрытия

#### 7. Ссылки на вкладки браузера

Мощная функция для сравнения и анализа информации с нескольких страниц одновременно:

**Как использовать:**
- Введите символ **`@`** в поле ввода сообщения
- Появится выпадающий список открытых вкладок браузера
- Выберите одну или несколько вкладок (до 5)
- Нажмите "Подтвердить" или Enter/Tab
- Вкладки отобразятся как badges с иконками и заголовками
- При отправке сообщения контент вкладок будет включен в запрос к AI

**Возможности:**
- **Фильтрация по названию**: Наберите текст после "@" для поиска (например: `@amazon`)

- **Множественный выбор**: Выбирайте несколько вкладок для комплексного анализа
- **Визуальные badges**: Иконки сайтов и укороченные заголовки для удобства

- **Сохранение в истории**: Все прикрепленные вкладки сохраняются в базе данных
- **Поддержка Compare Response**: Работает с альтернативными ответами от других моделей

**Примеры использования:**
- Сравнение цен товаров на разных сайтах: `@amazon @ebay сравни цены этих товаров`
- Анализ конкурентов: `@competitor1 @competitor2 сравни их функционал`

## Система инструментов (AI Tools)

Мощная система инструментов с поддержкой function calling для интеграции AI с внешними функциями и автоматизации задач.

### Возможности

- **Function Calling**: AI автоматически вызывает нужные инструменты на основе контекста
- **Рекурсивные вызовы**: AI может вызывать несколько инструментов последовательно (до 5 итераций)
- **Встроенные инструменты**: готовые решения для типовых задач
- **Пользовательские инструменты**: создание собственных инструментов с кастомными промптами
- **40+ DOM функций**: богатый набор функций для взаимодействия со страницей
- **Визуальные эффекты**: индикация работы инструментов (зеленая подсветка, кнопка остановки)
- **Интеграция с контекстным меню**: быстрый доступ к инструментам через правый клик
- **UI компоненты**: отображение процесса выполнения инструментов в чате

### Встроенные инструменты

#### 📄 Саммари страницы (`/summarize`)
- Извлекает текстовый контент страницы
- Создает краткое содержание на языке расширения
- Работает независимо от опции "Текущая страница"
- AI получает чистый текст и создает структурированное саммари

#### 📧 Собрать контакты (`/contacts`)
- Извлекает email, телефоны, Telegram со страницы
- AI уточняет тип контактов и формат вывода
- Поддерживаемые типы: all, email, phone, telegram
- Форматы вывода: text, json, csv
- Регулярные выражения для точного поиска контактов
- Отображение количества найденных контактов

#### ✏️ Заполнить форму (`/fillform`)
- Двухэтапный процесс: анализ полей → заполнение
- AI автоматически сопоставляет поля формы с данными пользователя
- Использует личную информацию из настроек
- Поддержка всех типов полей: text, email, tel, textarea, select
- Умный поиск полей по id, name, placeholder
- Отчет о заполненных полях

#### 🔍 Парсинг страниц (`/parse`)
Мощный инструмент для автоматического извлечения данных с множества страниц:

**Основные возможности:**
- **Умный поиск селекторов**: AI автоматически находит CSS селекторы по описанию на естественном языке (например, "заголовки товаров", "цены", "описания")
- **Множественные типы данных**: парсинг нескольких полей одновременно (названия, цены, описания и т.д.)
- **Циклический обход**: автоматический переход по ссылкам и сбор данных с множества страниц
- **Умная фильтрация ссылок**: AI анализирует все ссылки и выбирает только релевантные (товары, статьи и т.д.)
- **Форматы вывода**: JSON, CSV, текст
- **Визуальная индикация**: 
  - Пульсирующая подсветка границ экрана во время работы
  - Кнопка остановки парсинга
  - Прогресс-бар с количеством обработанных страниц
- **Защита от зависаний**: лимит попыток поиска селекторов (максимум 3), автоматическая остановка при ошибках
- **Пауза после 20 страниц**: система запрашивает подтверждение для продолжения

**Рабочий процесс:**
1. Пользователь описывает что нужно спарсить: "заголовки статей", "названия и цены товаров"
2. AI собирает все ссылки со страницы
3. AI фильтрует ссылки, оставляя только релевантные
4. AI переходит на первую страницу и автоматически находит CSS селекторы
5. AI извлекает данные с текущей страницы
6. AI переходит к следующей странице и повторяет процесс
7. После обработки всех страниц возвращает данные в выбранном формате

**Примеры использования:**
- Сбор списка товаров с ценами с интернет-магазина
- Извлечение заголовков и авторов статей с блога
- Парсинг контактов с каталога компаний
- Сбор описаний продуктов для анализа конкурентов

**Файлы:**
- `src/shared/tools/parsePages.ts` - основной инструмент парсинга
- `src/shared/tools/findElements.ts` - автоматический поиск CSS селекторов
- `src/content/domFunctions.ts` - функции извлечения данных и навигации
- `src/content/visualEffects.ts` - визуальные эффекты и UI индикаторы

### Как работают инструменты

1. **Пользователь вводит команду** (например `/fillform`)
2. **AI анализирует контекст** и вызывает нужный инструмент
3. **Инструмент выполняется** с визуальной индикацией (зеленая подсветка)
4. **Результат возвращается AI** для обработки
5. **AI может вызвать следующий инструмент** если нужно (например, получить поля → заполнить)
6. **Итоговый ответ** отображается в чате

### UI элементы

- **Кнопки инструментов**: отображаются на начальной странице чата
- **Команды `/`**: выпадающий список при вводе "/" в поле ввода показывает доступные инструменты с возможностью навигации стрелками и выбора через Enter/Tab
- **Отображение выполнения**: компонент `ToolExecutionDisplay` показывает:
  - Название инструмента
  - Состояние (ожидание входных данных, выполнение, результат, ошибка)
  - Входные параметры
  - Выходные данные или ошибки
- **Лоадер**: анимированный индикатор между вызовами инструментов
- **Визуальные эффекты страницы**:
  - Зеленая подсветка границ экрана
  - Кнопка "Остановить обработку" (AbortSignal)

## Контекстное меню для выделенного текста

## Режим разработчика

Специальная панель отладки для разработчиков, позволяющая отслеживать все API запросы к AI провайдерам без необходимости открывать DevTools браузера.

1. Откройте "Настройки" → "Общие"
2. Включите переключатель "Режим разработчика"

### Возможности

- **Отображение запросов/ответов**: Список всех API вызовов в реальном времени
- **Детальная информация**:
  - Временная метка (с миллисекундами)
  - Тип события (REQUEST/RESPONSE)
  - HTTP метод и статус
  - URL эндпоинта
  - Заголовки запроса (с маскировкой API ключей)
  - Тело запроса и ответа (с форматированием JSON)
  - Время выполнения запроса
  - Информация об ошибках
- **Интерактивный интерфейс**:
  - Сворачиваемые/разворачиваемые логи
  - Копирование данных в буфер обмена одним кликом
  - Прокрутка для больших ответов
  - Цветовая индикация (зеленый - успех, желтый - запрос, красный - ошибка)
  - Очистка логов одной кнопкой
  - Автоматическая подгрузка при открытии
- **Хранение**: Логи сохраняются в IndexedDB (макс. 200 записей)

### Структура лога

Каждая запись содержит:
```typescript
{
  id: string;           // Уникальный UUID
  timestamp: number;    // Unix timestamp
  type: 'request' | 'response';
  url: string;          // API endpoint
  method: string;       // GET, POST и т.д.
  status?: number;      // HTTP статус (для ответов)
  requestBody?: string; // Тело запроса (JSON)
  responseBody?: string;// Тело ответа (JSON)
  headers?: object;     // Заголовки (с маскировкой ключей)
  duration?: number;    // Время выполнения (мс)
  error?: string;       // Описание ошибки
}
```
