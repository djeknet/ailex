# AiLex - AI-powered Browser Extension

Браузерное расширение с чат-интерфейсом для взаимодействия с различными AI моделями (OpenAI, Anthropic и другие).

## Возможности

- 🤖 Поддержка множества AI провайдеров: OpenAI, Anthropic, OpenRouter, Grok, Gemini, LM Studio
- 💬 Чат с AI с поддержкой streaming ответов
- 📄 Автоматическое извлечение контекста текущей страницы
- 📎 **Прикрепление файлов и мультимодальность**:
  - 📄 Прикрепление файлов (документы, код, данные)
  - 🖼️ Прикрепление изображений с превью
  - 📸 Захват скриншотов с выбором области
  - 📷 Съемка фото с веб-камеры
  - 🎤 Голосовой ввод с распознаванием речи
  - 🎯 Выбор DOM элементов со страницы
  - ✅ Автоматическая проверка поддержки модели
  - 🗜️ Сжатие изображений при превышении лимита
- 🔧 **Система инструментов с function calling**: встроенные и пользовательские инструменты, интеграция с AI
- 🖱️ **Контекстное меню для выделенного текста**: 24 команды в 6 категориях + пользовательские инструкции
- 📱 Sidepanel интерфейс
- 🌙 Темная/светлая тема
- 🌍 Мультиязычность (EN/RU)
- 💾 История диалогов с различными режимами сохранения
- 📂 Организация чатов в папки
- 🔍 Поиск по истории чатов
- 🏷️ Автоматическое именование чатов из первого сообщения
- 📊 Отображение использованных операторов и токенов для каждого чата
- 🔗 Быстрый переход к сайту из истории чата
- 📊 **Вкладка History с двумя режимами**:
  - 💬 **Чаты**: история всех диалогов с группировкой по дням, пагинацией (30 чатов/страница)
  - 📈 **Статистика**: детальная аналитика использования токенов с фильтрами и графиками
- 🔧 **Режим разработчика**: панель отладки API запросов без DevTools

## Технологии

- **Frontend**: React + TypeScript
- **Build**: Vite + @crxjs/vite-plugin
- **UI**: shadcn/ui + TailwindCSS
- **State**: Zustand
- **Database**: IndexedDB (idb)
- **Icons**: lucide-react

## Установка

# Сборка для production

## Настройка

### AI Провайдеры

1. Откройте расширение
2. Перейдите в "Настройки" → "Операторы"
3. Введите API ключ для нужного провайдера
4. Нажмите "Тест" для проверки подключения

### Личная информация

## Использование

### Основной чат

1. Кликните на иконку расширения для открытия sidepanel
2. Выберите AI модель из списка
3. Введите запрос и отправьте
4. Включите "Текущая страница" для передачи контекста страницы

### История чатов

1. Нажмите на иконку "История" в хедере чата
2. В открывшейся панели вы увидите список всех чатов
3. Используйте поиск для быстрого нахождения нужного чата
4. Наведите курсор на чат для доступа к меню действий:
   - **Переименовать**: изменить название чата
   - **Переместить**: переместить чат в папку
   - **Удалить**: удалить чат безвозвратно

### Вкладка History

Полноценная страница с историей и аналитикой использования AI:

#### Режим "Чаты"

История всех диалогов с удобной навигацией:

- **Группировка по дням**: Сегодня, Вчера, N дней назад
- **Информация о чате**:
  - Название (генерируется автоматически)
  - Сайт с быстрым переходом (клик на badge)
  - Иконки использованных операторов
  - Количество токенов
  - Дата и время последнего обновления
- **Пагинация**: 30 чатов на страницу с навигацией
- **Клик на чат**: автоматически открывает сайт и загружает историю

#### Режим "Статистика"

Детальная аналитика использования токенов:

**Фильтры:**
- **Быстрый выбор периода**: Текущая неделя, Текущий месяц, Предыдущая неделя, Предыдущий месяц
- **Календарь дат**: От/До с валидацией (нельзя выбрать некорректный диапазон)
- **Фильтр по оператору**: Все операторы или конкретный AI провайдер

**Общие метрики:**
- Общее количество сообщений за период
- Общее количество токенов за период

**Графики:**

1. **Tokens per Day** (Bar Chart):
   - Динамика использования токенов по дням
   - Диапазон дат в подзаголовке
   - Tooltip с точным количеством

2. **By Operators** (Horizontal Bar Chart):
   - Распределение токенов по AI операторам
   - Сортировка по убыванию использования
   - Показывает все использованные операторы

3. **By Models** (Horizontal Bar Chart):
   - Топ-10 моделей по использованию токенов
   - Сортировка по убыванию
   - Автоматическое сокращение длинных названий

**Особенности:**
- Все графики адаптивные
- Tooltips с подсказками для полей фильтров
- Данные сохраняются в IndexedDB автоматически при каждом запросе
- Обработка пустых состояний ("No data available")

### Работа с папками

1. Нажмите кнопку "Новая папка" в панели истории
2. Введите название папки (по умолчанию "Безымянная папка")
3. Перемещайте чаты в папки через меню чата → "Переместить"
4. Нажмите на папку для раскрытия/скрытия чатов внутри
5. Наведите курсор на папку для доступа к меню:
   - **Переименовать**: изменить название папки
   - **Удалить**: удалить папку (чаты останутся)

### Информация о чатах

Для каждого чата отображается:
- **Название**: автоматически генерируется из первого сообщения
- **Сайт** (синий badge): кликабелен, открывает сайт в текущей вкладке
- **Операторы**: иконки использованных AI операторов в чате
- **Токены** (серый badge): общее количество использованных токенов
- **Дата создания**: заменяется на меню при наведении курсора

## Система инструментов (AI Tools)

Мощная система инструментов с поддержкой function calling для интеграции AI с внешними функциями и автоматизации задач.

### Возможности

- **Function Calling**: AI автоматически вызывает нужные инструменты на основе контекста
- **Рекурсивные вызовы**: AI может вызывать несколько инструментов последовательно (до 5 итераций)
- **Встроенные инструменты**: готовые решения для типовых задач
- **Пользовательские инструменты**: создание собственных инструментов с кастомными промптами
- **40+ DOM функций**: богатый набор функций для взаимодействия со страницей
- **Визуальные эффекты**: индикация работы инструментов (зеленая подсветка, кнопка остановки)
- **Интеграция с контекстным меню**: быстрый доступ к инструментам через правый клик
- **UI компоненты**: отображение процесса выполнения инструментов в чате

### Встроенные инструменты

#### 📄 Саммари страницы (`/summarize`)
- Извлекает текстовый контент страницы
- Создает краткое содержание на языке расширения
- Работает независимо от опции "Текущая страница"
- AI получает чистый текст и создает структурированное саммари

#### 📧 Собрать контакты (`/contacts`)
- Извлекает email, телефоны, Telegram со страницы
- AI уточняет тип контактов и формат вывода
- Поддерживаемые типы: all, email, phone, telegram
- Форматы вывода: text, json, csv
- Регулярные выражения для точного поиска контактов
- Отображение количества найденных контактов

#### ✏️ Заполнить форму (`/fillform`)
- Двухэтапный процесс: анализ полей → заполнение
- AI автоматически сопоставляет поля формы с данными пользователя
- Использует личную информацию из настроек
- Поддержка всех типов полей: text, email, tel, textarea, select
- Умный поиск полей по id, name, placeholder
- Отчет о заполненных полях

### Как работают инструменты

1. **Пользователь вводит команду** (например `/fillform`)
2. **AI анализирует контекст** и вызывает нужный инструмент
3. **Инструмент выполняется** с визуальной индикацией (зеленая подсветка)
4. **Результат возвращается AI** для обработки
5. **AI может вызвать следующий инструмент** если нужно (например, получить поля → заполнить)
6. **Итоговый ответ** отображается в чате

### UI элементы

- **Кнопки инструментов**: отображаются на начальной странице чата
- **Команды `/`**: выпадающий список при вводе "/" в поле ввода показывает доступные инструменты с возможностью навигации стрелками и выбора через Enter/Tab
- **Отображение выполнения**: компонент `ToolExecutionDisplay` показывает:
  - Название инструмента
  - Состояние (ожидание входных данных, выполнение, результат, ошибка)
  - Входные параметры
  - Выходные данные или ошибки
- **Лоадер**: анимированный индикатор между вызовами инструментов
- **Визуальные эффекты страницы**:
  - Зеленая подсветка границ экрана
  - Кнопка "Остановить обработку" (AbortSignal)

### Создание пользовательских инструментов

1. Перейдите в "Настройки" → "Инструменты"
2. Нажмите "Создать инструмент"
3. Заполните поля:
   - **Название**: отображается в UI
   - **Описание**: объясняет AI что делает инструмент
   - **Иконка**: эмодзи для визуализации
   - **Команда**: например `/mycommand`
   - **URL паттерн** (опционально): инструмент будет доступен только на определенных сайтах
   - **Промпт**: инструкция для AI, что нужно сделать
4. Инструмент автоматически появится в списке доступных

## Контекстное меню для выделенного текста

Мощная система команд для обработки выделенного текста на любой веб-странице с помощью AI.

### Как использовать

1. Выделите текст на любой веб-странице
2. Вызовите контекстное меню (правый клик мыши)
3. Выберите команду из категорий
4. Расширение автоматически откроется и выполнит запрос к AI
5. Результат отобразится в чате с цитатой исходного текста

### Категории и команды

#### 📊 Анализ
- **Проверить факты** (с веб-поиском) - Проверяет достоверность выделенного текста
- **Найти ошибки** - Анализирует текст на наличие логических ошибок
- **Оценить тональность** - Определяет эмоциональную окраску текста
- **SWOT анализ** - Проводит SWOT-анализ выделенной информации

#### ✏️ Редактирование
- **Исправить орфографию** - Корректирует орфографические и пунктуационные ошибки
- **Улучшить стиль** - Улучшает стилистику и читаемость текста
- **Сделать короче** - Сокращает текст, сохраняя основной смысл
- **Сделать длиннее** - Расширяет текст с дополнительными деталями
- **Упростить** - Упрощает сложные формулировки

#### 🔍 Исследование
- **Найти в интернете** (с веб-поиском) - Ищет дополнительную информацию по теме
- **Найти источники** (с веб-поиском) - Находит надежные источники по теме
- **Сравнить с аналогами** (с веб-поиском) - Сравнивает с похожими концепциями
- **Выделить ключевые слова** - Извлекает главные термины и концепции

#### 🎓 Образование
- **Объяснить простыми словами** - Объясняет сложные термины доступным языком
- **Привести примеры** - Дает практические примеры для понимания
- **Создать аналогию** - Создает понятные аналогии для объяснения
- **Связать с реальностью** - Показывает применение в реальной жизни

#### 🌐 Перевод
- **Перевести текст** - Переводит на язык расширения (отображается целевой язык)

#### 🎯 Комбинированные
- **Саммаризовать** - Создает краткое содержание текста
- **Расширить тему** - Развивает идеи из выделенного текста
- **Создать вопросы** - Генерирует вопросы для обсуждения
- **Создать план** - Структурирует информацию в план действий
- **Форматировать** - Улучшает форматирование и структуру

#### 📝 Обработать по инструкции
Если у вас есть сохраненные инструкции, они отображаются в этой категории:
- Каждая инструкция появляется как отдельный пункт меню
- При выборе: AI обрабатывает выделенный текст согласно инструкции
- Промт: `"Обработай следующий текст по инструкции: [содержимое инструкции]"`
- Автоматически обновляется при добавлении/изменении инструкций

### Особенности

- **Автоматическая локализация**: команды отображаются на языке расширения (RU/EN)
- **Веб-поиск**: некоторые команды автоматически активируют поиск в интернете
- **Сохранение цитат**: выделенный текст сохраняется как цитата в истории чата
- **Умное добавление**: если расширение открыто, задача добавляется в текущий чат
- **Динамическое меню**: категория инструкций появляется только если они есть

## Режим разработчика

Специальная панель отладки для разработчиков, позволяющая отслеживать все API запросы к AI провайдерам без необходимости открывать DevTools браузера.

### Активация

1. Откройте "Настройки" → "Общие"
2. Включите переключатель "Режим разработчика"
3. В нижней части расширения появится панель с логами API

### Возможности

- **Отображение запросов/ответов**: Список всех API вызовов в реальном времени
- **Детальная информация**:
  - Временная метка (с миллисекундами)
  - Тип события (REQUEST/RESPONSE)
  - HTTP метод и статус
  - URL эндпоинта
  - Заголовки запроса (с маскировкой API ключей)
  - Тело запроса и ответа (с форматированием JSON)
  - Время выполнения запроса
  - Информация об ошибках
- **Интерактивный интерфейс**:
  - Сворачиваемые/разворачиваемые логи
  - Копирование данных в буфер обмена одним кликом
  - Прокрутка для больших ответов
  - Цветовая индикация (зеленый - успех, желтый - запрос, красный - ошибка)
  - Очистка логов одной кнопкой
  - Автоматическая подгрузка при открытии
- **Хранение**: Логи сохраняются в IndexedDB (макс. 200 записей)

### Структура лога

Каждая запись содержит:
```typescript
{
  id: string;           // Уникальный UUID
  timestamp: number;    // Unix timestamp
  type: 'request' | 'response';
  url: string;          // API endpoint
  method: string;       // GET, POST и т.д.
  status?: number;      // HTTP статус (для ответов)
  requestBody?: string; // Тело запроса (JSON)
  responseBody?: string;// Тело ответа (JSON)
  headers?: object;     // Заголовки (с маскировкой ключей)
  duration?: number;    // Время выполнения (мс)
  error?: string;       // Описание ошибки
}
```
