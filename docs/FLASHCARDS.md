# Флэш-карточки в чате

## Описание

Реализована функция создания и отображения флэш-карточек из выделенного текста через контекстное меню.

## Как работает

1. **Пользователь** выделяет текст на странице
2. **Контекстное меню** → "Образование" → "Создать флэш-карточки"
3. **ИИ** анализирует текст и возвращает JSON с терминами и определениями
4. **Система** автоматически парсит JSON и отображает интерактивные карточки
5. **Пользователь** может перелистывать карточки и переворачивать их

## Архитектура

### 1. Тип данных
- `src/shared/types/flashcard.ts` - TypeScript интерфейс для карточки

### 2. Утилита парсинга
- `src/shared/utils/parseFlashcards.ts` - проверяет JSON и извлекает карточки
- Валидирует структуру данных
- Возвращает `null` для невалидных данных

### 3. Компонент отображения
- `src/ui/components/chat/FlashcardViewer.tsx` - интерактивный просмотр карточек
- Функции:
  - 📖 Переворот карточки (термин ↔ определение)
  - ◀️ Навигация назад
  - ▶️ Навигация вперёд
  - 🔢 Счётчик карточек (X / Y)

### 4. Интеграция
- `src/ui/components/chat/AIMessage.tsx` - автоматически детектирует JSON карточки
- Если ответ ИИ содержит валидный JSON флэш-карточек → показывает `FlashcardViewer`
- Иначе → показывает обычный текст через `Response`

### 5. Промпты
- `src/_locales/ru/messages.json` - промпт на русском
- `src/_locales/en/messages.json` - промпт на английском
- Улучшенные промпты требуют **чистый JSON** без дополнительного текста

## Формат JSON

```json
[
  {
    "term": "термин или понятие",
    "definition": "определение или описание"
  },
  {
    "term": "следующий термин",
    "definition": "его определение"
  }
]
```

## Пример использования

### Входные данные
Выделенный текст:
```
Manifest.json — это файл конфигурации браузерного расширения.
API — программный интерфейс для взаимодействия приложений.
```

### Ответ ИИ
```json
[
  {
    "term": "Manifest.json",
    "definition": "Файл конфигурации браузерного расширения"
  },
  {
    "term": "API",
    "definition": "Программный интерфейс для взаимодействия приложений"
  }
]
```

### Результат
Интерактивные карточки с навигацией и возможностью переворота.

## Технические детали

### Безопасность
- JSON парсится через `try-catch`
- Валидация всех полей перед отображением
- Нет XSS уязвимостей

### Производительность
- Парсинг выполняется один раз при рендере
- Мемоизация не требуется (короткий JSON)
- Быстрая навигация без перерендера

### UX
- Клик по карточке = переворот
- Стрелки = навигация
- Кнопка переворота = явное действие
- Подсказка внизу для новых пользователей
