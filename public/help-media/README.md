# Help Media Files

Эта папка содержит видео-демонстрации функций расширения AiLex.

## Naming Convention

Файлы должны именоваться по формату: `feature-[id].mp4`

## Список ожидаемых видео:

### Чат и модели
- `feature-ai-providers.mp4` - Множество AI провайдеров
- `feature-model-filters.mp4` - Фильтры моделей
- `feature-site-prompts.mp4` - Контекстно-зависимые промпты
- `feature-fullscreen-mode.mp4` - Полноэкранный режим чата
- `feature-message-editing.mp4` - Редактирование сообщений

### Медиа и прикрепления
- `feature-file-attachments.mp4` - Прикрепление файлов
- `feature-screenshot-capture.mp4` - Захват скриншотов
- `feature-tab-mentions.mp4` - Ссылки на вкладки через @
- `feature-voice-input.mp4` - Голосовой ввод
- `feature-webcam-capture.mp4` - Съемка с веб-камеры

### Инструменты
- `feature-function-calling.mp4` - Function Calling
- `feature-summarize-contacts.mp4` - Саммаризация и сбор контактов
- `feature-form-filling.mp4` - Автозаполнение форм
- `feature-page-parsing.mp4` - Парсинг страниц

### Контекстные меню
- `feature-text-context-menu.mp4` - Меню для выделенного текста
- `feature-field-context-menu.mp4` - Меню для полей ввода

### История и настройки
- `feature-chat-history.mp4` - История с группировкой
- `feature-token-statistics.mp4` - Статистика токенов
- `feature-export-import.mp4` - Экспорт и импорт настроек
- `feature-developer-mode.mp4` - Режим разработчика

## Технические требования

- **Формат**: MP4 (H.264 codec)
- **Рекомендуемое разрешение**: 1280x720 или 1920x1080
- **Рекомендуемая длительность**: 15-30 секунд
- **Размер файла**: до 5 MB
- **FPS**: 30

## Примечания

Если видео файл отсутствует, компонент VideoPlayer отобразит сообщение "Video file not found".
