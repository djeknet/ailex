# History Component - Storybook

Компонент для демонстрации вкладки "История" с тестовыми данными.

## Доступные Stories

### 1. Default
Основная демонстрация с полным набором тестовых данных:
- 8 чатов, распределенных по разным дням (сегодня, вчера, 3/5/7/10/15 дней назад)
- Статистика за последние 30 дней
- Данные по 5 операторам: Anthropic, OpenAI, Gemini, Grok, OpenRouter
- Разные модели для каждого оператора

### 2. Empty History
Пустое состояние:
- Нет чатов
- Нет статистики
- Демонстрирует placeholder состояния

### 3. Only Chats
Только чаты без статистики:
- 8 тестовых чатов
- Пустая статистика
- Проверка работы вкладки "Чаты"

### 4. Many Chats
Большое количество чатов (50 шт):
- Тест производительности
- Проверка группировки по дням
- Скроллинг большого списка

## Тестовые данные

### Чаты
- Распределены по разным датам
- Разные сайты (stackoverflow.com, github.com, etc.)
- Каждый чат содержит 4 сообщения (2 от пользователя, 2 от AI)
- Разные операторы для разных чатов

### Статистика
- 30 дней данных
- 5 операторов с разными моделями
- Реалистичные значения токенов (1000-6000)
- Количество сообщений (5-25)
- Поле `spent` оставлено как `undefined`

## Как использовать

```bash
npm run storybook
```

Откройте браузер и перейдите на `http://localhost:6006`

Найдите "Pages/History" в боковом меню.

## Mock функции

Story использует mock версии:
- `chrome.runtime.sendMessage` для получения статистики
- `chrome.tabs.query` и `chrome.tabs.update` для навигации
- `useChatStore.loadAllChats` для загрузки чатов
- `useChatStore.loadMessages` для загрузки сообщений

Это позволяет тестировать компонент без реального backend и Chrome Extension API.
